# AEGIS QuantOS 0.2.0 — release notes

Replaces the isolated M0 paper demonstration with a persistent local research workstation. Includes ten connected UI views, transactional paper execution, multi-symbol risk reservations, next-open cost-aware fills, participation-limited partial fills, bracket handling, automation, backtests, bootstrap scenarios, DCF, alerts, model adapter, connector contracts, audit export and account reconciliation.

The source audit led to preserving independent Kronos trajectories rather than using averaged paths as an uncertainty distribution. Forecasts remain research-only.

Build refinement fixed form step validation, disappearing computed output after redraw, mobile overflow, a 512-bar input cap that incorrectly restricted the mini model, and integrity checks missing from automated execution entrypoints. The final unit/integration and browser test reports are in evidence/.

See ../README.md for the actual limitations, launch commands and optional model installer.
